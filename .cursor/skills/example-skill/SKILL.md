# Example Skill

## Instructions

- Use this skill as a **starting point** when authoring new skills.
- Copy this directory, rename it, and update the frontmatter and sections below.

When applying this skill:

1. Identify the task or workflow the user cares about.
2. Follow any checklists or steps defined in the skill.
3. Keep responses concise and focused on the requested outcome.

## Sections to Customize

When you copy this template, consider adding:

- **Quick start**: 3–5 bullet points describing the core workflow.
- **Checklists**: step-by-step lists for fragile or multi-step tasks.
- **Templates**: example output formats the agent should follow.
- **References**: links to `reference.md`, `examples.md`, or scripts in a `scripts/` subdirectory if needed.
